# Running the workshop

The workshop is designed in **three phases**, which can be run one after the
other or separately. In its full format, it lasts **from twenty minutes**
(public stand) **to half a day** (classroom). If you are short of time or
space, feel free to leave out some elements or present only one part!

<div class="grid cards" markdown>

-   :material-leaf:{ .lg .middle } **1. Discovering the plant cell**

    ---

    The leaf box, the cell model and, if possible, a look through the
    microscope.

    [:octicons-arrow-right-24: See phase 1](cellule.md)

-   :material-magnify-plus:{ .lg .middle } **2. Diving into the chloroplast**

    ---

    All the way to the photosynthetic chain, the most hands-on part of the
    workshop. With a simplified version for young children.

    [:octicons-arrow-right-24: See phase 2](chloroplaste.md)

-   :material-cards:{ .lg .middle } **3. The cards**

    ---

    What happens when the environment changes? A stress, its consequences,
    and how the cell responds.

    [:octicons-arrow-right-24: See phase 3](../cartes.md)

</div>
