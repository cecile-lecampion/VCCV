# Imprimer le modèle

Cette page rassemble tout ce qu'il faut pour imprimer et assembler le modèle
de la chaîne photosynthétique.

## Télécharger les fichiers

<!-- Quand vous publiez une « Release » sur GitHub avec un zip de toutes les
     pièces, remplacez l'adresse ci-dessous par celle du zip.
     Le lien « latest » pointe toujours vers la version la plus récente. -->

[:material-download: Télécharger toutes les pièces (zip)](https://github.com/cecile-lecampion/VCCV/releases/latest){ .md-button .md-button--primary }

Le fichier zip contient toutes les pièces au format **STL**, prêtes à être
ouvertes dans votre logiciel d'impression (Cura, PrusaSlicer, Bambu Studio…).

??? question "Je n'ai pas d'imprimante 3D, comment faire ?"
    De nombreux lieux proposent des imprimantes 3D en accès libre :
    fablabs, médiathèques, établissements scolaires, universités…
    Apportez simplement le fichier zip téléchargé ci-dessus.

## Réglages d'impression conseillés

| Réglage | Valeur conseillée |
|---|---|
| Matériau | PLA |
| Hauteur de couche | 0,2 mm |
| Remplissage | 15 % |
| Supports | à compléter selon les pièces |
| Diamètre de buse | 0,4 mm |

!!! tip "Astuce"
    Imprimer chaque élément de la chaîne dans une couleur différente aide
    beaucoup le public à repérer les acteurs de la photosynthèse.
