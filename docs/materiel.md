# Le matériel

Le set se compose d'éléments **imprimés en 3D**, que l'on peut monter,
démonter, associer ou utiliser séparément. Ils suivent le zoom de l'atelier,
de la plante entière jusqu'à la chaîne photosynthétique.

!!! warning "Modèles en cours de finalisation"
    Certains éléments évoluent encore et d'autres arrivent bientôt
    (thylakoïdes, chaîne de transport d'électrons). Les fichiers les plus
    récents sont toujours dans les dossiers indiqués ci-dessous.

## À prévoir en plus des impressions

- des **billes**, qui représentent les électrons ;
- des **bonbons**, qui représentent le sucre produit (pas d'électron… pas de bonbon !) ;
- si possible, un **microscope** pédagogique pour observer une feuille ;
- les [cartes](cartes.md), imprimées sur papier épais.

## Télécharger les fichiers

Chaque bouton « Fichiers 3D » ci-dessus ouvre le dossier correspondant.
Cliquez sur un fichier, puis sur l'icône :material-download: (« Download raw
file ») en haut à droite pour l'enregistrer.

Vous pouvez aussi télécharger **tout le projet d'un coup** (modèles, cartes,
guide, photos) :

[:material-download: Tout télécharger (zip)](https://github.com/cecile-lecampion/VCCV/archive/refs/heads/main.zip){ .md-button }

??? question "Je n'ai pas d'imprimante 3D, comment faire ?"
    De nombreux lieux proposent des imprimantes 3D en accès libre :
    fablabs, médiathèques, établissements scolaires, universités…
    Apportez simplement les fichiers téléchargés.

??? question "Il n'y a pas d'accroche pour les étiquettes de l'eau et de l'oxygène sur le photosystème II. Comment faire ?"
    Les petites accroches imprimées en PLA sont trop fragiles pour supporter
    le poids et la manipulation des étiquettes. Nous leur avons préféré un
    trou dans lequel nous collons un petit clou ou, encore mieux, un
    taquet d'étagère comme ceux des meubles en kit (on en a souvent en
    surplus). Nous mettrons les modèles à jour dès que nous aurons trouvé
    une meilleure solution !
